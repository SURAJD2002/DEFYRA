## What is DEFYRA?
DEFYRA helps organizations identify, validate, and reduce risks in autonomous AI systems, agents, and agentic workflows. As AI moves from simply generating answers to taking real-world actions, DEFYRA validates whether those actions are appropriately controlled, authorized, and bounded.

### Core Attack Path Validated by DEFYRA:
```
Untrusted Input → AI / Agent → Context / RAG → Memory → Tools → Identity → Permissions → APIs → Business Systems → Business Impact
```

## Quick Start (Development)

```bash
# 1. Navigate to Web App
cd apps/web

# 2. Install dependencies
npm install

# 3. Configure environment
cp ../../.env.example .env.local

# 4. Start local development server
npm run dev

# 5. Run tests
npm test
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

---

## Project Structure
- `apps/web`: Next.js 14/15 App Router web application with enterprise dark cybersecurity UI.
- `database/migrations`: PostgreSQL schema definitions for multi-tenant isolation.
- `database/seeds`: Seed test definitions for the AI security catalog.
- `docs/`: Comprehensive architecture, decisions, security, database, and API specifications.
